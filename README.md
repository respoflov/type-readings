# 연애 유형 진단소 (Type Readings)

19개의 상황 문항으로 나의 연애 유형(8가지)을 알아보고, 생년월일과 MBTI를 더하면 사주와 MBTI를 함께 읽는 심화 리딩을 보여 주는 PWA입니다. 재미로 보는 셀프 리딩 콘텐츠입니다.

- 배포: https://respoflov.github.io/type-readings/

## 주요 기능

- 표현(직진·신중) · 온도(불꽃·잔잔) · 판단(낭만·현실) 3축, 8유형 진단
- 사주(만세력 간이 계산)와 MBTI를 결합한 심화 리딩과 종합 결과
- 연애 유형 궁합과 사주 궁합
- 결과 보관함(다시보기), 라이트·다크 테마

외부 API나 서버 호출 없이 모든 판정을 브라우저 안에서 규칙 기반으로 계산합니다.

## 파일 구성

```
index.html              앱 전체 (HTML·CSS·JS·데이터 한 파일)
manifest.webmanifest    PWA 설치 정보
sw.js                   오프라인 캐시 서비스 워커
docs/                   설계 문서 (문항·판정 규칙·리딩 원문·디자인 토큰·사주 로직)
CLAUDE.md               Claude Code로 수정할 때 지키는 규칙
히스토리.md             작업 이력
```

## 데이터 저장

진단 진행 상태는 `sessionStorage`, 보관함만 `localStorage`에 저장되며 어디로도 전송되지 않습니다.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 동작합니다.

## 홈 화면에 추가

- 아이폰: 브라우저에서 주소를 연 뒤 공유 버튼(↑) → 홈 화면에 추가
- 안드로이드: 브라우저 메뉴(⋮) → 홈 화면에 추가 또는 앱 설치
