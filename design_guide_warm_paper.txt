====================================================
디자인 가이드 — "미색모조 기록장" 스타일
(출처: 이상형 셀프 체크 PWA / 용도: 브리핑·보고서 등 문서형 결과물)
====================================================

[1] 컨셉 한 줄
- "미색모조지 위에 웜 브라운 잉크로 정갈하게 쓴 기록물."
- 화면보다 '종이 문서'의 인상. 채도 낮은 웜톤 + 딥그린 한 방울.
- 장식은 괘선·점선·작은 점(불릿 시일) 정도로 최소화.

[2] 컬러 토큰 (그대로 복사해 쓰기)
- --paper : #f6f0e1  배경(미색모조지)
- --card  : #fdfaf1  카드·본문 영역(종이보다 반 톤 밝게)
- --ink   : #3c352a  본문 텍스트(웜 다크브라운, 순검정 금지)
- --sub   : #8b8069  보조 텍스트·캡션·메타 정보
- --line  : #e4dac3  괘선·테두리(연한 베이지)
- --green : #2f5d44  딥그린 포인트(제목 마침점, 소제목, 핵심 라벨)
- --green-soft : #e9efe8  딥그린의 옅은 배경(포커스·하이라이트)
- --red   : #a3473b  경고·중요 표시(차분한 적갈색, 쨍한 빨강 금지)
- --red-soft   : #f2e3de  적갈색의 옅은 배경
- 비율 감각: paper/card 90% + ink/sub 텍스트 + green 5% 미만 +
  red는 정말 중요한 표시에만.

[3] 타이포그래피
- 제목·소제목: 'Gowun Batang'(명조 계열 세리프), 굵기 700.
  → 문서의 "표제지·장 제목" 느낌을 담당.
- 본문: 시스템 산세리프 스택
  ('Apple SD Gothic Neo','Pretendard','Noto Sans KR',system-ui,sans-serif)
- 크기 스케일(모바일 기준): 대제목 26px / 장 제목 18px /
  소제목 14.5~15.5px / 본문 15px / 캡션·메타 11~13px.
- 행간 1.55. 자간은 제목에만 살짝(letter-spacing .02em).
- 시그니처 디테일: 대제목 끝에 딥그린 마침점 하나
  (예: "결과 보고서<span style="color:#2f5d44">.</span>")
- 숫자는 tabular-nums(시각·표에서 자리 흔들림 방지).

[4] 레이아웃·간격
- 콘텐츠 최대 폭 640px, 중앙 정렬, 좌우 패딩 16px. 1단 구성.
- 카드(내용 블록): 배경 --card, 테두리 1px --line,
  둥근 모서리 14px, 안쪽 패딩 14~18px, 카드 간격 10~12px.
- 그림자 사용하지 않음(종이 느낌 유지). 구분은 테두리와 여백으로.
- 장(섹션) 구분: 딥그린 명조 소제목 + 아래 1px --line 밑줄.
- 항목 구분: 점선(dashed) 1px #eee5d0 — 실선보다 부드러운 리듬.

[5] 컴포넌트 패턴 (문서용으로 번안)
- 문서 헤더: 중앙 정렬 명조 대제목(+딥그린 마침점) → 한 줄 부제(--sub)
  → 메타 정보(날짜·작성자)를 알약(pill) 테두리 안에 11.5px로.
- 번호 라벨: 항목 번호를 딥그린 명조 볼드 2자리(01, 02…)로 표기.
- 라벨 칩: 둥근 알약 형태, 배경 --paper + 테두리 --line.
  강조 칩은 배경 --ink에 흰 글씨(반전). 딥그린 칩은 '긍정·확정' 의미로만.
- 중요 표시: ★ 또는 작은 점 + 적갈색 텍스트, 옅은 적갈 배경(--red-soft).
  해당 블록 테두리를 적갈 계열로 살짝 강조하는 것까지 허용.
- 표/대조 항목: 좌측에 좁은 라벨 열(명조, 44px 내외, --sub 또는 --green)
  + 우측 내용. "나/이상형" 구조를 "현황/제안", "AS-IS/TO-BE"로 번안 가능.
- 각주·범례: 문서 말미 중앙 정렬 11.5px --sub.

[6] 톤 원칙 (하지 말 것)
- 순검정(#000)·순백(#fff) 금지 — 항상 웜톤으로 반 톤 눌러서.
- 그림자·그라데이션·네온·채도 높은 색 금지.
- 딥그린을 넓은 면적(배경·큰 버튼 다수)에 쓰지 말 것. 포인트로만.
- 강조 수단을 색에만 의존하지 말고 명조/고딕 대비, 굵기, 괘선으로.
- 아이콘보다 문자·기호(★, ›, ✎, 점) 우선 — 기록물의 담백함 유지.

[7] 재사용 스니펫 (CSS 변수 블록)
:root{
  --paper:#f6f0e1; --card:#fdfaf1; --ink:#3c352a; --sub:#8b8069;
  --line:#e4dac3; --green:#2f5d44; --green-soft:#e9efe8;
  --red:#a3473b; --red-soft:#f2e3de; --radius:14px;
}
body{ background:var(--paper); color:var(--ink);
  font-family:'Apple SD Gothic Neo','Pretendard','Noto Sans KR',
  system-ui,sans-serif; line-height:1.55; }
h1,h2,h3{ font-family:'Gowun Batang',serif; }
