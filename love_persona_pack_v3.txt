[변경 이력]
- v2→v3: 문항 상황 제시형 전면 개편(3지선다), 폼 중복 소재
  5건 교체, 시그널 지표 2종 신설, 스위치형 동점 규칙 도입,

  ×4불릿(샘플 2유형 선작성). 모드 B 버전명은 미부여.

[공통 규칙] ※ 수정 시 버전 올림
1. 톤: 1차 재미 / 2차 심화 리딩. "재미로 보는 콘텐츠" 면책 명시.
2. 축은 자체 8유형. 심화에서 사주=선천 잠재(씨앗),
   MBTI 수치=현재 발화 강도(계기판), 문항=행동 표본.
3. PWA + GitHub Pages 정적 배포. 판정은 전부 규칙 기반,
   외부 API 금지. 규칙은 "입력→출력" 대조표로 고정.
4. 1차 문항: 상황 제시형 3지선다(A/중간/B), 축당 5문항
   + 시그널 2문항 = 총 17문항. 어투는 둥글게(단정 금지),
   방향성은 유지.
5. 채점: A=1 / 중간=0.5 / B=0. 축 합계 3 이상=앞 성향,
   2 이하=뒤 성향, 2.5=스위치형(심화 시 확정).
6. 기존 이상형 체크 폼(ideal_type_form_items.txt)과 소재
   중복 금지: 만남 빈도·기념일·여행·데이트 코스·갈등 화해·
   연락 빈도 선호·질투·SNS 공개·서프라이즈는 소재로 안 씀.
7. 시(時) 미상: 삼주 간이 리딩 + 결과에 표기.
8. 낙인성 표현 금지(회피형·가벼움 등 직접 명명 대신 순화).
9. UTF-8(BOM 없음), 버전 관리.

-- 시그널 문항 (축 미반영, 별도 출력) --

시그널 출력 규칙:
- S1=A → "설렘 연료 시그널": 자극이 연애의 연료인 타입.

  서술(낙인 없이).
- 중간 응답은 시그널 미발동. A/B 반대 방향은 각각
  "안정 지향" / "밀착 환영" 한 줄 코멘트만.

(b) MBTI 슬라이더 → 후천 발화 강도
  - E–I → 표현축 (E=직진) / T–F → 판단축 (F=낭만)
  - S–N → 온도축 (2026-07-26 개정, v1 미사용 → 축 힌트로 반영):
    N(직관상상)=불꽃 / S(현실감각)=잔잔
  - J–P → 판단축 보조 힌트 (2026-07-26 개정, v1 미사용 → 축 힌트로 반영):
    P(즉흥)=낭만 / J(계획)=현실. T–F가 주 신호이며, T–F가
    중립(55% 미만 치우침)일 때만 J–P가 대신 힌트를 제공한다.
    T–F와 J–P가 서로 다른 방향을 가리키면 신뢰할 수 없다고
    보고 중립(힌트 없음) 처리한다.
  - A–T = 「정서 안정도」 지표 (축 방향 판정에 사용 금지, 변경 없음):
    · A(안정형): 자신감·회복 빠름 → 같은 성향도 "여유 기반"
      으로 발현 (예: 직진도 담백한 직진)
    · T(격동형): 불안 민감·자기의식·완벽주의 → 같은 성향도
      "확인 욕구 기반"으로 발현 (몰입처럼 보이는 불안,
      혹은 한발 물러서는 신중함)
    → 최종 리딩 문장의 '발현 방식' 서술 + 재확인 문항의
      어투 조정에 사용.
  - 모든 지표는 %값을 발화 강도로 근거문에 직접 인용.
    55% 미만은 "중립"(힌트 없음).
  - "MBTI 발화 강도" 표기는 축 고정 알파벳(E/N/F/P)이 아니라
    실제 %가 더 큰 쪽 알파벳을 표기(2026-07-26 개정, index.html
    domPct/mbtiStrengthLine). 예: EI=70이면 "I70%"로 표기(과거엔
    항상 "E30%"로 고정 표기해 실제 우세 성향과 어긋났음).
  - 슬라이더 자체도 2026-07-26 개정: 좌우 색 채움(accent-color)이
    "채워진 쪽=그 라벨의 우세"로 오해되는 시각 버그가 있어, 얇은
    균일 트랙 + 단일 색 손잡이(점)로 교체. 방향성 오해 소지 제거.
  - 판정근거의 MBTI 힌트 문장에 강도 표현 추가(mbtiStrengthOf/
    intensityWord): 우세 %가 85%↑="매우 강하게", 70%↑="뚜렷하게",
    그 외(55~70%)="약간"으로 차등 서술해 극단값/사잇값을 구분.

(c) 종합 판정 — 입력→출력 대조표 (촘촘·고정)
  소스: ⓐ행동(1차 응답) ⓑ후천(MBTI) ⓒ선천(사주)
       + ⓓ피드백 응답("맞나요?") + ⓔ재확인 응답
  축별 판정:
  ┌ 입력 상태 ──────────────┬ 처리 ─────────────────┐
  │ ⓐⓑⓒ 3소스 방향 일치      │ 즉시 확정               │
  │ ⓐ=ⓑ, ⓒ만 다름           │ 확정(행동·후천 우선),    │
  │                          │ "선천과 다른 발화" 서술   │
  │ ⓐ만 다름 or ⓑ만 다름     │ 재확인 문항 2개 →        │
  │                          │ ⓐ가중2+ⓑ1+ⓒ1 합산 확정 │
  │ ⓐ 스위치형(2.5)          │ ⓑⓒ 방향으로 확정,       │
  │                          │ 둘도 갈리면 재확인 2개    │
  │ ⓓ="글쎄요"               │ 불일치 없어도 최저 확신    │
  │                          │ 축 1개 재확인 추가        │
  └──────────────────────┴───────────────────────┘
  일관성 등급(결과에 표기, "확신 유형" 표현 폐기):
  - 일관형: 3축 모두 3소스 방향 일치
  - 발화형: 1축 이상에서 선천≠(행동=후천)
    → "타고난 씨앗과 다른 방향이 현재 발화 중"으로 해석
  - 탐색형: 재확인 후에도 혼재 축 존재
    → "지금은 스스로를 알아가는 구간"으로 긍정 서술
  근거문 템플릿(축당 3줄 고정):
  "표현축 | 행동: 직진 4.5/5 · 후천: E 78% 발화 중 ·
   선천: 병화(양간)=직진 씨앗 → 일관형 직진"

■ 샘플 ① 「불도저 로맨티스트」 (직진·불꽃·낭만)
  태그: ENFP·ESFP·ENFJ 감성 / 불(양·사자·사수) / 화(火)
  [평소 성격]
  - 하고 싶은 게 생기면 몸이 먼저 움직이는 추진력 소유자
  - 처음 만난 사람과도 금방 말을 트는 리액션 부자, 모임의
    텐션 담당을 자주 맡음
  - 고민은 담아두기보다 말하면서 푸는 편, 혼자 있으면
    오히려 생각이 많아짐
  - 숨은 강점은 회복 탄력 — 넘어져도 일어나는 속도가 빠르고
    주변까지 끌어올리는 긍정 전염력이 있음
  [연애 스타일]
  - 좋아하면 온 동네가 알게 되는 타입, 밀당보다 정면 돌파
  - 표현이 크고 즉각적 — 즉흥 데이트와 깜짝 연락이 잦음
  - 초반 몰입도 최상, 상대의 일상에 빠르게 스며듦
  - 사랑받는 확신이 들 때 가장 빛나고, 반응이 미지근하면
    눈에 띄게 시무룩해짐
  [반전 포인트]
  - 시작은 불도저지만 상대 감정 변화에는 의외로 예민한
    안테나를 갖고 있음
  - 화려한 표현파인데 정작 깊은 속마음 얘기는 타이밍을 재는 편
  - 안정기에 접어들면 문득 "설렘 어디 갔지?" 점검에 들어가기도
  - 다툴 때 목소리는 커도 뒤끝은 짧음 — 화해도 직진
  [잘 어울리는 유형]
  - 꿀조합: ⑤ 속불꽃 시인 — 속도는 달라도 같은 낭만 언어를 씀
  - 거울조합: ①끼리 — 축제 같은 연애, 페이스 조절 합의가 관건
  - 무난조합 팁: 잔잔 유형과 만나면 온도차를 '서운함'이 아닌
    '휴식'으로 번역해볼 것
  - 환장조합: ⑧ 신뢰 적금러 — 속도 차 최대, 서로 외계인
    관찰의 재미(존중이 열쇠)

■ 샘플 ⑧ 「신뢰 적금러」 (신중·잔잔·현실)
  태그: ISTJ·ISFJ 감성 / 땅(황소·처녀·염소) / 토(土)
  [평소 성격]
  - 루틴과 약속을 지키는 데서 안정감을 얻는 성실 기질
  - 초면엔 말수가 적지만 곁을 준 사람에게는 꾸준하고 세심함
  - 스트레스는 혼자 정리할 시간이 필요한 편, 정돈되면
    담담하게 해결책부터 찾음
  - 숨은 강점은 기억력 — 지나가듯 한 말을 오래 기억해
    행동으로 되돌려줌
  [연애 스타일]
  - 호감의 증거는 말보다 행동: 데려다주기, 챙기기, 시간 엄수
  - 연락은 화려하지 않아도 일정하고 끊기지 않는 안정형
  - 진도는 천천히, 대신 한 계단씩 확실하게 올라감
  - 신뢰가 쌓일수록 표현이 늘어나는 '후불제 애정형'
  [반전 포인트]
  - 무뚝뚝해 보여도 약속과 기억은 여덟 유형 중 가장 정확함
  - 좀처럼 화내지 않지만 신뢰가 깨지는 순간엔 가장 단호해짐
  - 익숙해지면 의외의 장난기와 능청 유머가 튀어나옴
  - 변화를 꺼리는 듯해도 확신이 서면 누구보다 과감히 결정함
  [잘 어울리는 유형]
  - 꿀조합: ④ 든든 매니저 — 표현 속도만 다를 뿐 신뢰의
    언어가 같음
  - 거울조합: ⑧끼리 — 세상 평온, 단 먼저 다가갈 역할 정하기
  - 무난조합 팁: 불꽃 유형과 만나면 잦은 표현을 '재촉'이 아닌
    '애정'으로 번역해볼 것
  - 환장조합: ① 불도저 로맨티스트 — 서로에게 없는 것을
    배우는 조합
