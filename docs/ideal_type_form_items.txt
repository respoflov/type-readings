====================================================
이상형 매칭 구글 폼 — 섹션별 항목(주제) 초안 (v2)
====================================================

[공통 규칙]
- 각 주제는 "나" 문항과 "이상형" 문항 한 쌍으로 사용.
- "이상형" 문항에는 반드시 「상관없다」 보기를 포함.
- 모든 객관식에는 「기타(자유서술)」 보기를 포함.
  (구글 폼의 '기타...' 옵션 기능 사용)
- 아래 보기들은 후보안이며, 검토 후 확정 예정.


----------------------------------------------------
섹션 0. 기본 정보  ※ 매칭용
----------------------------------------------------
1) 이름(닉네임 가능) — 단답
2) 성별 — 객관식 / 기타(자유서술)
3) 나이(출생연도) — 단답
4) 거주 지역(시/군/구 단위) — 단답
5) 희망 상대 성별 — 객관식 / 기타(자유서술)
6) 희망 상대 나이대 — 동갑±2 / 연상 선호 / 연하 선호 / 상관없다
   / 기타(자유서술)
7) 만남 가능 지역 범위 — 같은 시/군 내 / 1시간 이내 / 장거리 가능
   / 상관없다 / 기타(자유서술)
※ 개인정보 수집·이용 동의 문구 필수(용도·보관기간·파기 명시)
※ 매칭 성사 시 연락 수단이 필요하므로, 구글 폼 설정에서
  "이메일 주소 수집"을 켜두는 것을 권장(별도 문항 불필요)
