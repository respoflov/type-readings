첫 프롬프트로 붙여넣을 내용
----------------------------------------------------

이 레포는 계속 진행 중인 "연애 유형 진단소"(한국어 연애 유형
진단 PWA) 프로젝트야. CLAUDE.md는 자동으로 로드될 텐데, 그 안의
"불변 규칙"과 "연쇄 수정 규칙"부터 먼저 숙지해줘.

그리고 다음 두 파일을 반드시 먼저 읽어줘:
- 히스토리.txt — 지금까지 세션별로 무엇을·왜 바꿨는지 전체 기록
- docs/saju_sibsung_logic_v1.txt — 사주 심화 로직 상세(십성·
  지장간 계산 근거, 과다/부족 판단 기준, 실제 검증값)

읽고 나면 현재 상태를 알고 있어야 해:
- "일간에 일지까지 더하면" 섹션은 히스토리.txt [7](4차 수정)에서
  완전히 일주(60갑자, ILJU) 기반으로 전면 재구현 완료됐어 —
  더 이상 미해결 사항 아님. DAYSTEM과 동일한 4카테고리×4불릿
  구조를 60개 일주 전체에 적용(총 960불릿), 근거는
  docs/saju_sibsung_logic_v1.txt [6]·[11] 참조.
- 앱 아이콘도 하트 모티브에서 3축 진단 슬라이더 모티브로
  전면 교체됐고, 궁합 보기 탭에 사주 궁합이 신설됐고, 스플래시
  +랜딩 화면이 추가됐어. 자세한 내용은 히스토리.txt [7] 참조.

작업 방식은 이전 세션과 동일하게 진행해줘:
1. 요청이 여러 개면 순서를 먼저 제안하고 승인받은 뒤 하나씩
   진행 (한 번에 다 하지 말 것 — 누락·충돌 위험)
2. index.html을 수정할 때마다 sw.js의 CACHE 버전 문자열 +1
3. 로컬 테스트는 .claude/launch.json의 "love-type-static"
   (python3 http.server)으로 띄우기 — 이 Mac은 Node.js가 없어서
   node --check 대신 브라우저에서 직접 함수 호출로 검증
4. 검증 전에 반드시 서비스워커/캐시부터 지운 뒤(브라우저에서
   navigator.serviceWorker.getRegistrations()로 전부 unregister
   + caches.keys()로 전부 caches.delete()) force navigate로
   재로드할 것 — 안 그러면 오래된 스크립트가 계속 서빙돼서
   "함수가 undefined" 같은 가짜 버그로 착각하게 됨
5. 완료 후 브라우저에서 실제로 클릭/입력해서 확인하고,
   "요청 반영"과 "Claude 판단 수정"을 구분해서 보고

지금은 코드를 수정하지 말고, 위 파일들을 읽고 현재 상태를
파악·요약만 해줘. 다음 메시지로 이번 턴 수정 요청사항을 전달할게.
